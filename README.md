 ## Overview

This is a full-stack MERN (MongoDB, Express, React, Node.js) application for **user management**.  
Features include:  

- User registration and management  
- Search users by name or email  
- Update user status (Active/Inactive) via dropdown  
- Delete users  
- Export users data to CSV  
- Profile image upload with default placeholder  
- Pagination for user list  

---

## Tech Stack

- **Frontend:** React, React-Bootstrap, Axios  
- **Backend:** Node.js, Express  
- **Database:** MongoDB (Atlas or local)  
- **Deployment:** Frontend on Netlify, Backend on Render  

---

## Features

1. **User Management**
   - Add, edit, view, and delete users
   - Profile picture upload  
   - Status toggle (Active/Inactive)

2. **Search & Pagination**
   - Search users dynamically
   - Pagination for better UX

3. **Export to CSV**
   - Download all users data as a CSV file

4. **Responsive UI**
   - Built with React-Bootstrap for mobile-friendly layout
